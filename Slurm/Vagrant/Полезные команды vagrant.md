
| Команда            | Что делает                                                  |
| ------------------ | ----------------------------------------------------------- |
| vagrant status     | Покажет, какие ВМ запущены                                  |
| vagrant suspend    | Заморозить все ВМ (сохраняется состояние, экономит ресурсы) |
| vagrant resume     | Разморозить ВМ                                              |
| vagrant halt       | Корректно выключить ВМ                                      |
| vagrant destroy -f | Удалить ВМ полностью (данные пропадут!)                     |
