Слой 1: FROM базовый image 


| Слой |                    |                                                                                                                                        |
| ---- | ------------------ | -------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | FROM debian:jessie | Скачивает базовый образ и потом на его основе внутри образа будет выполнять остальные команды, которые мы указываем в нашем dockerfile |
| 2    | RUN                | команда для настройки OS                                                                                                               |
| 3    | RUN                | команда для установки пакетов OS                                                                                                       |
| 4    | RUN                | команда для установки модулей и библиотек                                                                                              |
| 5    | ADD                | файлы приложения                                                                                                                       |
| 6    | ENTRYPOINT         | команда для запуска приложения                                                                                                         |

Лучшие практики:

- .dockerignore
- Отключение кэшей: RUN rm -rf  /var/lib/apt/lists/* (apt get тут хранит кэши)
  ```
  RUN set -ex && \
      apt-get update && \
      apt-get install -y nginx && \
      rm -rf /var/lib/apt/lists/*
  ```
- Установка и удаление в одном шаге
- Порядок выполнения шагов
- Логи в stdout/stderr
  ```
  RUN set -ex && \
      ln -sf /dev/stdout /var/log/nginx/access.log && \
      ln -sf /dev/stderr /var/log/nginx/error.log
  ```
*тут используем еще одну директиву RUN , потому что эта задача никак не связана у нас с установкой nginx*
- COPY и ADD - если мы не знаем, в чем разница между директивой COPY и ADD, то вам нужна директива COPY. COPY умеет просто скопировать файлы внутрь контейнера, директива ADD это так же умеет, но если файлы, которые копируются являются архивами, то эти файлы будут распакованы.
- ENTRYPOINT и CMD : ENTRYPOINT это та команда, которая должна выполняться при старте контейнера, а CMD это какие-то параметры для этой команды.
