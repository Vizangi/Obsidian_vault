
1 `docker run -t -i debian:jessie bash` 
* -t -i  мы указываем этими ключами, что собираемся запустить консоль
* debian:jessie - образ
* bash - последний параметр, который мы будем запускать внутри контейнера

`root@7cdc2e7c27c3:/#` - после выполнения команды видим это, мы внутри контейнера

`docker ps -a`  -  показывает не только запущенные контейнеры, но и все остальные.


### Что произошло ?

docker run debian:jessie bash ==
1. docker pull debian: jessie  -  *докер обратился к registry( месту, где хранятся image для запуска наших контейнеров и получил оттуда debian версии jessie*
2. docker create debian:jessie bash - *из полученного только что image создал контейнер внутри с командой bash *
3. docker start containerID - *ну тут понятно*



2 `docker run -d -p 8080:80 nginx:1.13` 
- *-d ключ означает, что мы запускаем контейнер в бекграунд режиме
- *-p обозначает порт, говорит о том, что мы пробрасываем наш локальный порт 8080 внутрь контейнера на порт 80 контейнера

`docker logs ContainerName` - показывает логи



3 ` docker rm -f ContainerName `
-  *rm - remove 
* *-f  - force 


4 ` docker run -d -p 8080:80 -v $PWD/default.conf:/etc/nginx/conf.d/default.conf nginx:1.13 ` 
- *-v - volume. Мы можем подключить файл default.conf внутрь контейнера /etc/nginx.../default.conf*
