

### Docker Compose

Эта утилита - одна из частей все экосистемы Docker. Представляет собой "обертку", написанную на питоне, над самим Docker, которая позволяет на основании описания в Docker-сompose .yml файлов запускать многоконтейнерные инфраструктуры.
Docker compose создает при этом собственную отдельную сеть для каждого запущенного проекта и в рамках этой отдельной сети, контейнеры внутри этой сети могут обращаться друг к другу по именам сервисов.


Поднятие любого проекта == `docker-compose up -d`


Разработка с использованием Docker:
1. Стандартный Dockerfile
2. Стандартный docker-compose.yml
3. Добавляем нужные зависимости
4. Собираем образ
5. Запускаем окружение
6. Пишем приложение
7. Повторяем с п.3 до достижения успеха
