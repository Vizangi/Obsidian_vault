# Namespaces
## - PID NS 

- Процессы в PID ns видят только процессы в том же ns
- У каждого PID ns своя нумерация начинающаяся с 1
- Когда завершается PID 1 весь ns перестает существовать


## - NET NS

- Процессы в рамках своего net ns получают свое сетевое окружение
     - Сетевые интерфейсы ( в том числе local host - *lo )
     - Таблицу маршрутизации
     - Правила iptables
     - Сокеты
- Veth ( что-то типа бриджа между контейнером и реальностью )
- Общий lo для нескольких контейнеров

## - MNT NS (Mount NameSpace)

- Процесс может иметь свою root fs
- Процесс может иметь свои приватные маунты
     - /tmp
     - /sys и /proc
 *Почитать про список параметров в ядре, которые мы можем тюнить отдельно для каждого контейнера*

## - USER NS

- Позволяет мапить GID/UID
     - Можно смапить UID 0 (root) в нерутовый UID в хостовом NS
