- Проверить аптайм на всех серверах:
```
ansible webservers -i inventory.ini -a "uptime" -u vagrant
```

- Проверить версию ядра:
```
ansible webservers -i inventory.ini -a "uname -r" -u vagrant
```

- Установить пакет:
```
ansible webservers -i inventory.ini -m apt -a "name=htop state=present" -b -u vagrant
```
_Флаг `-b` означает `--become`, то есть выполнить с правами sudo_
