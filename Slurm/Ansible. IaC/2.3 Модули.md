>[!example] main_task.yml
>```
>- name: install repo  # устанавливает репозиторий для yum
>   yum_reposotory:
>   name: "mogodb-org-{{ mongodb_version }}" # и так далее
>   
>- name: install mongodb  # устанавливает под пакет mongodb.org
>   yum:
>     name: "mongodb-org"
>     state: present
>     
>- name: Template configuration options  # Настраивает конфигурацию сервера
>   template:
>     src: "etc/mongodb.conf.j2"
>     dest: "etc/mongodb.conf"
>     owner: root
>     mode: 0644
>    when: mongodb_version == "3.6"
>    notify: restart mongodb
>    
>- name: start and enable service  # Этот модуль запускает сервис
>   become: true
>   service:
>     name: "mongodb"
>     state: started
>     enabled: yes
>     
>- include_tasks: backups.yml  # выполняется на этапе сценария, туда можно добавлять условные операторы
>   when: mongodb_backup_enable
>
>- import_tasks: iptables.yml  # импортирует task безусловно, запускается при первом запуске сценария ( все импорты объединяются в 1 файл, который выполняется)
>```


>[!example] iptables.yml
>```
>- name: Check required dirs
>   file:
>     path: "{{ item }}"
>     state: directory
>    with_items:
>      - "{{ mongodb_sb_check }}"
>      - "{{ mongodb_sb_libexec }}"
>      - "{{ mongodb_sb_etc }}"
>      - 
>- name: Iptables whitelist
>   template:
>     src: "{{ mongodb_iptables_config }}.j2"
>     dest: "{{ mongo_sb_etc }}/{{ mongodb_iptables_config }}"
>     mode: 0644
>   register: mongodb_whitelist
>   
>- include_tasks: "iptables-sysvinit.yml"
>   when: ansible_distribution_major_version|int <= 6
>   
>- include_tasks: "iptables-systemd.yml"
>    hen: ansible_distribution_major_version|int >= 7
>- name: Iptables service check script
>    template:
>     src: "_sb_iptables.mongodb"
>     dest: "{{ mongo_sb_check }}"
>     mode: 0755
>    
>```

*register: mongodb_whitelist эта команда позволяет запомнить состояние нашего таска, т.е. создается переменная mongodb_whitelist и туда записывается различная информация о том, что там наш таск делал, изменился ли он, если изменился вообще, завершился ли успешно и тд , и эту переменную можно проверить в следующих тасках*
