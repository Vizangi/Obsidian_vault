>[!example] каталог host_vars, файл ingress-1.s04.slurm.io
>```
>ansible_ssh proxy:
>ingress-1.s04.slurm.io
>```

*все переменные, которые есть в этом файле, будут применены к нашему серверу, который называется ingress-1.s04.slurm.io*


Каталог group_vars содержит
*/all* - каталог, встроенная группа, в нее входят все сервера, которые есть в инвентаре. Все переменные из этого каталога будут применены ко всем серверам, которые есть в инвентаре.
*student04* - все переменные, которые есть в этом файле, будут применены к группе student04
>[!example] all.yml
>```
>admin_allowed_list:
>    - bond
> 
>base_etc_hosts_local: []
>
>base_etc_hosts_common: []
>all.yml (END)
>```
