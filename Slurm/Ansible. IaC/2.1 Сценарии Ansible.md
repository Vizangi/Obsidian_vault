Ansible сущности

- Task            - процесс настройки разбит на task, каждый task - вызов модуля Ansible
- Variables    - позволяют писать универсальные роли
- Template    - написаны на языке Jinja 2. Позволяет создавать различные файлы на                                      конфигурируемых серверах.
- Handler       - специальные таски, которые выполняются в самом конце. Обычно в них                               делают рестарт сервиса.
- Role            - таски, переменные, темплейты и хендлеры для удобства объединяют в роли                         по логическому принципу. Например роль для настройки виртуального хоста                       с сайта, роль добавления пользователей.


### Что содержится внутри роли


| /defaults  | хранятся переменные роли, которые переопределятся в других местах                                                                                         |                                                                                                            |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| /files     | тут содержатся файлы, которые копируются на сервер с помощью модуля `copy`                                                                                | файлы не изменяются                                                                                        |
| /handlers  | содежит хендлеры                                                                                                                                          |                                                                                                            |
| /tasks     | самый главный каталог, в котором находятся наши таски, <br>которые роль выполняет для настройки сервера                                                   | внутри:<br>backups.yml<br>iptables-systemd.yml<br>iptables.yml<br>main.yml - главный файл<br>main_task.yml |
| /templates | файлы, которые динамически генерируются. Модуль `template` копирует эти каталоги и изменяет согласно всем переменным, которые есть в инвентаре, роли и тд |                                                                                                            |
| /vars      | тут содержатся переменные, которые лучше называть константами, они используются в роли но их нельзя переопределить                                        |                                                                                                            |
*файл main.yml содержит*
```
- include_tasks: main_task.yml
  when: "'mongodb' in roles"
```
*включить файл main_task.yml на выполнение, если в списке ролей этого сервера есть mongodb*
