- Настройка сетевого оборудования
- Конфигурирование серверов
- Деплой приложений

### Установка ansible (через vagrant -> начало [[Установка и быстрая настройка Vagrant.|тут]])

1. выполняем команды
```
vagrant ssh ansible
```

```
sudo apt update
sudo apt install ansible -y
```

2. проверяем версию
```
ansible --version
```

3. генерируем ключи SSH (чтоб Ansible мог лазить на другие машины без пароля):

```
ssh-keygen -t rsa -b 2048
```

4. Копируем ключи на целевые машины

```
ssh-copy-id vagrant@ip_машины
```

_(Первый раз спросит `yes/no` — пишем yes. Пароль от пользователя vagrant обычно `vagrant`)_. Повторим для второй машины.

### Создание инвентаря и тест

1. Создаем файл со списком хостов:

> [!example] bash
> ```bash
> nano inventory.ini
> ```

2. Вставляем туда:

> [!example] ini
> ```
> [webservers]
> ip-адрес-машины1
> ip-адрес-машины2
> ```

сохраняем Ctrl + O, Enter. Выход - Ctrl + x

3. Первый тест (ping):

```
ansible webservers -i inventory.ini -m ping -u vagrant
```
если видим зеленый SUCCESS для обоих IP - поздравляю, ты запустил первый Ansible.
