Переменные в Ansible имеют приоритет. Переменные могут устанавливаться в нескольких местах, чем выше приоритет этого места, то значение этого места перезаписывает все ранее установленные значения.

- # Extra vars                      - самый высокий приоритет
- ## Playbook vars
- ### inventory/host_vars
- #### inventory file or script host vars
- ##### inventory/group_vars
- role/defaults                                             - самый низкий приоритет

*Extra vars - переменные, которые установлены при запуске playbook в командной строке через ключ - e*
