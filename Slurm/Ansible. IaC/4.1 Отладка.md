У Ansible есть несколько инструментов, которые нам помогут отладить наши сценарии.
- Проверка синтаксиса и стиля кода
  https://github.com/ansible/ansible-lint

- Фреймворк для тестирования
  https://molecule.readthedocs.io/en/latest
  
- Ключи ansible-playbook:
  --syntax-check 
  --step 
  --check 
  --diff
  
- ansible.cfg: stdout_callback = debug
  
- Playbook strategy: debug


### Ansible Debugger

>[!example] ini
>```
># ansible.cfg
>[defaults]
>enable_task_debugger = True
>```
*включает отладчик глобально для всех запусков на этой машине*


другой способ: В плейбуке (play или task)

>[!example] yaml
>```
># На уровне play (всего плейбука)
>- name: Deploy app
>    hosts: webservers
>    debugger: on_failed # <- сработает при любой ошибке в play
>    tasks:
>     - name: Install package
>        apt:
>          name: nginx
>        debugger: on_failed # <- сработает только если эта задача упадёт
>```

валидные значения debugger:

| Значение              | Когда сработает                        |
| --------------------- | -------------------------------------- |
| always                | Перед каждой задачей                   |
| never                 | Никогда (отключает глобальный настрой) |
| on_failed             | Только если задача упадет с ошибкой    |
| on_unreachable        | Если хост недоступен                   |
| on_skipped            | Если задача пропущена                  |
| on_failed_unreachable | Комбинация двух выше                   |

Еще один способ:
Через переменную окружения

>[!example] bash
>```
># Временное включение для одного запуска
>ANSIBLE_ENABKLE_TASK_DEBUGGER=TRUE ansible-paybook play.yml
>
># Или экспортировать в сессию
>export ANSIBLE_ENABLE_TASK_DEBUGGER=True
>```
