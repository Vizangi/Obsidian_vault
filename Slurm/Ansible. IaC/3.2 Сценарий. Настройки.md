### Способы конфигурации Ansible

Ansible можно конфигурировать 4мя способами:
- ANSIBLE_CONFIG (Переменные окружения) ( высший приоритет )
- ansible.cfg ( в текущем каталоге)
- ~/.ansible.cfg ( в домашнем каталоге )
- /etc/ansible/ansible.cfg - основной , дефолтный вариант



>[!example] ansible.cfg
>```
>[defaults]
>timeout                          = 120
>role_path                        = ./core/roles
>remote_port                      = 22
>become                           = true
>become_user                      = root
>forks                            = 100
>log_path                         = ./logs/ansible.log
>#inventory                        = inventory/
>host_key_checking                = False  # отключает режим проверки отпечатка сервера
>retry_files_enabled              = True
>stdout_callback                  = debug # позволяет выводить красивые сообщения о дебаге
>#strategy_plugins = /usr/lib/python2.7/site-packages/ansible_mitogen/plugins/strategy
>#strategy = mitogen_linear
>
>[paramiko_connection]
>record_host_keys                 = False
>
>[ssh_connection]   # аргументы, которые передаются при соединении с серверами
>ssh_args                         = -o ControlMaster=auto -o ControlPersist=600s -o UserKnownHostsFile=/dev/null
>pipelining                       = True
>control_path                     = /tmp/ansible-ssh-%%h-%%p-%%r
>
>ansible.cfg(END)
>```
