

- 1. подготовка инфры

```bash
# Шаг 0: директория темы
mkdir -p ~/monitoring-course/02-grafana
cd ~/monitoring-course/02-grafana

# Шаг 1: системный юзер и директории
sudo useradd --no-create-home --shell /bin/false grafana
sudo mkdir -p /etc/grafana /var/lib/grafana /var/log/grafana
```

- 2. качаем бинарник

```bash
cd /tmp
GRAFANA_VERSION=$(curl -sL "https://api.github.com/repos/grafana/grafana/releases/latest" | grep -oP '"tag_name": "\K[^"]+'))
echo "Ставим Grafana $GRAFANA_VERSION"
wget -q "https://dl.grafana.com/oss/release/grafana-${GRAFANA_VERSION#v}.linux-amd64.tar.gz"
tar xf grafana-${GRAFANA_VERSION#v}.linux-amd64.tar.gz
cd grafana-${GRAFANA_VERSION#v}
ls -la    # увидишь: bin/grafana, bin/grafana-server, conf/, public/
```

- 3. раскладываем

```bash
sudo cp bin/grafana-server /usr/local/bin/
sudo chown root:root /usr/local/bin/grafana /usr/local/bin/grafana-server

#Дефолтный конфиг и статика
sudo cp -r conf /etc/grafana/
sudo cp -r public /usr/share/grafana/

# Права
sudo chown -R grafana:grafana /var/lib/grafana /var/log/grafana /etc/grafana
```

- 4. конфиг grafana.ini
```bash
cp /etc/grafana/conf/defaults.ini ~/monitoring-course/02-grafana/grafana.ini
```

в VS Code

```ini
[server]
```

Деплой

```bash
sudo cp ~/monitoring-course/02-grafana/grafana.ini /etc/grafana/grafana.ini
sudo chown grafana:grafana /etc/grafana/grafana.ini
sudo chmod 640 /etc/grafana/grafana.ini
```

- 5. systemd-юнит

```ini
[Unit]
Description=Grafana
Wants=network-online.target
After=network-online.target

[Service]
User=grafana
Group=grafana
Type=simple
ExecStart=/usr/local/bin/grafana-server \
    --config=/etc/grafana/grafana.ini \
    --homepath=/usr/share/grafana \
    --pidfile=/var/run/grafana/grafana-server.pid \
    cfg:default.paths.logs=/var/log/grafana \
    cfg:default.paths.data=/var/lib/grafana \
    cfg:default.paths.plugins=/var/lib/grafana/plugins
Restart=on-failure
RestartSec=5
LimitNOFILE=65536

[Install]
WantedBy=multi-user.target
```

деплой:

```bash
sudo cp ~/monitoring-course/02-grafana/grafana.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now grafana
sudo systemctl status grafana --no-pager | head -5
```

## Фикс по результату

**Вариант А: find показал `/tmp/grafana-*/public/emails`** (значит, наш cp его почему-то не донёс):

```bash
sudo cp -r /tmp/grafana-*/public/emails /usr/share/grafana/public/
```

**Вариант Б: find показал emails в другом месте** (например, `/tmp/grafana-*/emails` или `.../conf/emails`) — копируем туда, где их ждёт glob (в public/):

```bash
sudo cp -r <путь_из_find> /usr/share/grafana/public/emails
```

**Вариант В: find не нашёл ничего** (в совсем свежих релизах шаблоны могли уехать из тарбола) — лабный workaround,.glob должен совпасть хотя бы с чем-то:

```bash
sudo mkdir -p /usr/share/grafana/public/emails
echo "lab placeholder" | sudo tee /usr/share/grafana/public/emails/placeholder.html > /dev/null
echo "lab placeholder" | sudo tee /usr/share/grafana/public/emails/placeholder.txt > /dev/null
```

Дальше во всех вариантах:

```bash
sudo chown -R grafana:grafana /usr/share/grafana/public/emails
sudo systemctl restart grafana
sudo systemctl status grafana --no-pager | head -5
curl -s http://localhost:3000/api/health && echo
```

закрыли проблему с `emails/`


#### Финальная настройка
тепер графана не находила`core plugins`


```bash
# 1. Что лежит в public/ тарбола (должны быть img/, plugins/, fonts/ и т.д.)
find /tmp/grafana-*/public -type d | head -20

# 2. Что сейчас в /usr/share/grafana/public/
ls -la /usr/share/grafana/public/
find /usr/share/grafana/public -type d | head -20
```

Скорее всего, увидишь, что в тарболе есть `public/plugins/` или `public/app/plugins/` (это и есть core plugins), а в `/usr/share/grafana/public/` их нет.


## Фикс: копируем public/ целиком заново

Удаляем битое и копируем заново с правильной структурой:

```bash
# удаляем текущее битое public
sudo rm -rf /usr/share/grafana/public

# копируем заново из тарбола
sudo cp -r /tmp/grafana-*/public /usr/share/grafana/

# права
sudo chown -R grafana:grafana /usr/share/grafana/public

# рестарт
sudo systemctl restart grafana
sudo systemctl status grafana --no-pager | head -5
curl -s http://localhost:3000/api/health && echo
```
