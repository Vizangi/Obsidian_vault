
systemctl нет, делаем руками

```
echo slave1 | sudo tee /etc/hostname
sudo sed -i 's/mon-01/slave1/g' /etc/hosts
sudo hostname -F /etc/hostname   # применит без ребута
```

Сначала посмотри имя интерфейса: `ip a` (обычно `ens18`/`eth0`). Потом правим `/etc/network/interfaces`:

```
auto ens18
iface ens18 inet static
    address 192.168.X.10/24      # придумай из своей подсети
    gateway 192.168.X.1
    dns-nameservers 1.1.1.1 8.8.8.8
```

Первый запуск: базовая гигиена

```
sudo hostnamectl set-hostname master
sudo apt update && sudo apt upgrade -y
sudo apt install -y curl wget git vim htop jq unzip make tree \
    ca-certificates gnupg lsb-release iproute2 dnsutils netcat-openbsd
timedatectl status   # проверь, что NTP sync = yes. Для мониторинга точное время критично!
```

Прописываем имена

На **обеих** ВМ и на **локальной машине** добавь в `/etc/hosts` (или в `C:\Windows\System32\drivers\etc\hosts`, если с винды):
*будем ходить по именам, а не по IP*
```
192.168.X.10   master
192.168.X.11   slave1
```

На локалке
```
ssh-keygen -t ed25519 -C "monitoring-course"   # если ключа еще нет
ssh-copy-id master
```

В `~/.ssh/config` (или в настройках Remote-SSH у VSCode):

```
Host master
    HostName master
    User shtan
    IdentityFile ~/.ssh/id_ed25519
```

Дом для артефактов курса

## Шаг 1. Фиксируем статический IP (сразу, чтобы коннект не отваливался после ребута)

```
sudo nano /etc/network/interfaces
```

```
source /etc/network/interfaces.d/*

auto lo
iface lo inet loopback

auto enp0s3
iface enp0s3 inet static
    address 192.168.X.10/24
    gateway 192.168.X.1
    dns-nameservers 1.1.1.1 8.8.8.8
```

Применить: `sudo systemctl restart networking`. Проверить: `ip a` — адрес должен стать тем, что прописал.

## Шаг 2. Имя `master` на хосте (Windows)

Блокнот **от админа** → открой `C:\Windows\System32\drivers\etc\hosts` → дописать:

```
192.168.X.10   master
```
