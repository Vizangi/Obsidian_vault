Кастомный exporter - набор баш-скриптов, которые выполняют HTTP запросы к разными ресурсам и анализируют результаты и преобразуют их в метрики, читаемые Prometheus через Node Exporter Textfile Collector.

## Шаг 1.

```python
#!/usr/bin/env python3
import http.server
import time
import random

class MetricsHandler(http.server.BaseHTTPRequestHandler):
    def do_GET(self):
        if self.path != '/metrics':
            self.send_response(404)
            self.end_headers()
            return
        
        # Собираем метрики (пример: аптайм + случайный счетчик)
        uptime = time.time() - self.server.start_time
        counter = random.randint(1, 100)
        
        # Формат Prometheus: metric_name{labels} value
        metrics = f"""# HELP custom_exporter_uptime_seconds How long the exporter has been running
# TYPE custom_exporter_uptime_seconds gauge
custom_exporter_uptime_seconds {uptime:.2f}

# HELP custom_requests_total Total number of requests
# TYPE custom_requests_total counter
custom_requests_total{status="ok"} {counter}
custom_requests_total{status="error"} {counter // 10}
"""
        
        self.send_response(200)
        self.send_header('Content-Type', 'text/plain; version=0.0.4')
        self.end_headers()
        self.wfile.write(metrics.encode())
    
    def log_message(self, format, *args):
        pass  # глушим стандартный лог

if __name__ == '__main__':
    server = http.server.HTTPServer(('', 9200), MetricsHandler)
    server.start_time = time.time()
    print(f"Custom exporter listening on :9200")
    server.serve_forever()
```

- порт 9200 - не пересекается с другими
- Метрика `custom_requests_total{status="ok"}` - это counter ( только растет)
- Метрика `custom_exporter_uptime_seconds` - это gauge (может расти и падать)
- Формат `имя{label="value"} число` - это и есть Prometheus text format
- `# HELP` и `# TYPE` — метаданные, Prometheus их парсит
