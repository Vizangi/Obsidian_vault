
### Шаг 0. Директория

```bash
mkdir -p ~/monitoring-course/04-process-exporter
```

- -p флаг означает --parents. Его значение зависит от конкретной команды, но общий смысл — «создать/обработать промежуточные звенья автоматически» или «не ругаться, если уже существует».

## Шаг 1. Юзер

В данном случае мы создавали юзеров без shell. Для process exporter - специально запускаем от root, потому что он читает `/proc/<pid>` для **ЧУЖИХ** процессов, а файл `/proc/<pid>/io` (метрики ввода и вывода) читается **только владельцем процесса или root**. Под обычным юзером получим дырки в метриках.

## Шаг 2. Качаем бинарник

```bash
cd /tmp
PE_VERSION=$(curl -sL "https://api.github.com/repos/ncabatoff/process-exporter/releases/latest" | grep -oP '"tag_name": "\K[^"]+')
echo "Ставим Process Exporter $PE_VERSION"
wget -q "https://github.com/ncabatoff/process-exporter/releases/download/${PE_VERSION}/process-exporter-${PE_VERSION#v}.linux-amd64.tar.gz"
tar xf process-exporter-${PE_VERSION#v}.linux-amd64.tar.gz
sudo cp process-exporter-${PE_VERSION#v}.linux-amd64/process-exporter /usr/local/bin/
process-exporter --version
```

## Шаг 3. Конфиг групп (сначала в репо!)

Файл `04-process-exporter/config.yml` (создали конфиг в нашей репе):

```yaml
process_names:
  - name: "{{.Comm}}"        # имя группы = имя процесса
    cmdline:
      - 'prometheus'
      - 'grafana'
      - 'node_exporter'
      - 'process-exporter'
      - 'sshd'
```

Как это работает: каждая запись - это **группа**, `cmdline` - список regex'ов против полной командной строки процесса; что сматчилось - попало в группу. `name` - шаблон имени группы: {{.Comm}} подставит имя бинарника (prometheus, grafana...). Хочешь группу "всё живое" для песочницы - замени cmdline на `- '.+'`, но серий станет много.

Деплой:

```bash
sudo mkdir -p /etc/process-exporter
sudo cp ~/monitoring-course/04-process-exporter/config.yml /etc/process-exporter/
```

## Шаг 4. Systemd-юнит (в репо!)

Файл `04-process-exporter/process-exporter.service`:

```yaml
[Unit]
Description=Process Exporter
Wants=network-online.target
After=network-online.target

[Service]
User=root
Type=simple
ExecStart=/usr/local/bin/process-exporter \
    --procfs /proc \
    -config.path /etc/process-exporter/config.yml
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
```

Деплой:

```bash
sudo cp ~/monitoring-course/04-process-exporter/process-exporter.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now process-exporter
sudo systemctl status process-exporter --no-pager | head -5
```
